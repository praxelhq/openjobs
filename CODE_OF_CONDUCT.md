# Code of Conduct

We want OpenJobs to be a useful place to build job-discovery infrastructure. Be respectful in issues, pull requests, and discussions. Focus criticism on code and evidence; do not harass, discriminate against, or expose private information about other people.

Maintainers may edit or remove contributions that break these expectations and may restrict participation when needed. Report concerns privately through the contact route in [`SECURITY.md`](SECURITY.md) if public discussion would expose a person or a security issue.
